# 📁 HR Analytics Dataset Documentation

This folder contains the **HR dataset** used in the project  
*Employee Performance and Retention: An HR Analytics Case Study.*

The dataset includes over **15,000 employee records**, providing detailed information about each employee’s experience, performance, compensation, and attrition status.  
It serves as the foundation for the SQL analysis, Power BI dashboards, and case study report.

---

## 🧾 Dataset Overview

| Column Name | Description | Example Value |
|--------------|--------------|----------------|
| `satisfaction_level` | Employee job satisfaction (0–1 scale) | 0.72 |
| `last_evaluation` | Last performance evaluation score (0–1 scale) | 0.85 |
| `number_project` | Number of projects completed by the employee | 5 |
| `average_monthly_hours` | Average number of hours worked per month | 220 |
| `time_spend_company` | Number of years spent at the company | 3 |
| `work_accident` | Whether employee had a work accident (1 = Yes, 0 = No) | 0 |
| `promotion_last_5years` | Whether employee was promoted in the last 5 years (1 = Yes, 0 = No) | 0 |
| `department` | Employee department or business unit | Sales |
| `salary` | Employee salary level (low, medium, high) | medium |
| `left` | Attrition flag (1 = Left company, 0 = Still employed) | 1 |

---

## ⚙️ File Information

- **File Name:** `HR_comma_sep.csv`  
- **File Type:** CSV (Comma-Separated Values)  
- **Rows:** 14,999  
- **Columns:** 10  

---

## 🧩 Data Source
The dataset was sourced from a publicly available HR dataset commonly used for employee attrition and retention analysis.  
It has been cleaned and formatted for use in SQL and Power BI.

---

## 🧠 Insights Enabled by This Dataset

This dataset supports exploration of:
- Employee attrition trends  
- Salary vs. retention analysis  
- Performance evaluation and workload impact  
- Tenure-based turnover  
- Effects of promotions and work accidents on attrition  

---

## 🚀 How to Use
1. Download `HR_comma_sep.csv`.  
2. Import into your SQL environment or Power BI Desktop.  
3. Set the table name as `hr_data` for compatibility with the provided SQL scripts.  
4. Refresh visuals and run queries to replicate insights.
